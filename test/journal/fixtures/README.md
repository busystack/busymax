# Historical journal queue fixture

`legacy-range-v28.sqlite.gz` contains a disposable database generated by
BusyMax commit `df88856c2ec98aae37152f5cdc887c99de3bf6b3`. The offline journal
editor added a future-range exception while retaining the ordinary exception
at the same original DATE recurrence position. The database also contains a
confirmed, unaffected journal. All addresses and calendar data are synthetic.

To regenerate in an isolated detached checkout at that commit, copy
`generate_legacy_range.dart` to its `test/journal/a2_legacy_fixture_test.dart`
and run the checked-in SDK and shared dependency setup. Point
`BUSYMAX_LEGACY_JOURNAL_FIXTURE` at a new private file and run that test with
`flutter test test/journal/a2_legacy_fixture_test.dart`. Compress the resulting
closed database with `gzip -n -c`. Generated identifiers may differ across runs.
The retained uncompressed fixture has SHA-256
`744428d027bd9f98f16b9d7dbd9947886e0758115cfc619a1eac316378868562`.

The current regression opens a copy, checks recovery while pending, verifies
that replay fails before sending a request, reopens the failed state, and
requires an explicit choice before a conditional replacement can replay.
